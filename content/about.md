Hi, I'm **Vitalii** 👋

I'm a Java developer, and I've been writing backend code for more than 12 years: mostly Spring Boot, microservices, PostgreSQL, Kafka and everything that keeps them running in the cloud.

My favourite hobby is keeping up with what's new: new Java releases, new tools, new trends. Lately that's been a lot of AI tooling like Claude Code, MCP and RAG. Whenever I learn something, I try it out for real, and then write about it here. If something took me a weekend of digging to understand, I'd like it to take you twenty minutes of reading.

## What you'll find here

- How Java actually works under the hood: the memory model, concurrency, builds
- PostgreSQL stuff I ran into in production
- Spring and Hibernate gotchas
- AI tools for developers, tried hands-on
- Notes on how teams and projects really work

## When I'm not writing backend code

I make games! Game development is my other hobby. You can check out what I've built on [Google Play](https://play.google.com/store/apps/details?id=com.sukachvv).
